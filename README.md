# Compressed-Air Systems

Work on compressed-air engines and their control, University of Groningen.

## CAE-bench

The compressed-air Wankel engine test bench: bill of materials, assembly,
wiring, calibration, firmware, control software and the 2024 measurement data.
Start at `CAE-bench/README.md`.

## compressed-air-ph-control

Port-Hamiltonian control of compressed-air engines. Simulation code for
"Energy-Based Speed Regulation of Compressed-Air Engines",
Munoz-Arias, Esquivel-Sancho and del Puerto-Flores.
